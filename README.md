# Landing Page Plot Bot

Página de apresentação de um bot de moderação para Discord, feita para estudar HTML e CSS.

🔗 **Ver ao vivo:** https://Dev-Erick-Rodrigo.github.io/landing-plotbot/

## O que tem na página

- Cabeçalho com logo e menu de navegação
- Seção principal com título, subtítulo e botões de chamada para ação
- Lista do que o bot faz: verificação CAPTCHA, banimento automático de links suspeitos e avisos/banimento manual
- Rodapé com logo
- Layout responsivo (computador, tablet e celular)

## Tecnologias

- HTML5
- CSS3 (flexbox, `@media` queries, transições e efeitos de hover)
- Google Fonts

## Como rodar

Baixe o repositório e abra o arquivo `index.html` no navegador. Não precisa instalar nada.
